# 🐍 Structure of a Python Program

## 📌 Overview

This project demonstrates the basic structure of a Python program. It explains how Python statements, variables, input/output functions, and comments are used to write and execute a simple program.

## 🚀 Features

- Demonstrates the basic structure of Python code.
- Explains variables and assignment statements.
- Uses input and output functions.
- Demonstrates comments and basic arithmetic operations.
- Beginner-friendly and easy to understand.

## 🛠️ Technologies Used

- **Programming Language:** Python 3
- **Platform:** Google Colab / Python IDE

## 📂 Code

```python
# Basic structure of a Python program

# Display a welcome message
print("Welcome to Python Programming!")

# Declare variables
name = "Akshansh"
age = 18

# Display variable values
print("Name:", name)
print("Age:", age)

# Perform a simple calculation
a = 10
b = 20
sum = a + b

print("Sum:", sum)
```

## 🧠 How It Works

1. **Comments:** Lines beginning with `#` explain the code and are ignored by Python.
2. **Output:** The `print()` function displays information on the screen.
3. **Variables:** Variables store values such as names, ages, and numbers.
4. **Assignment:** The `=` operator assigns a value to a variable.
5. **Expressions:** Python evaluates arithmetic expressions such as `a + b`.
6. **Execution:** Python executes the statements in order, from top to bottom.

## 📖 Basic Structure of Python

A simple Python program generally contains:

1. **Comments:** Explain the purpose of the code.
2. **Variables:** Store data.
3. **Input Statements:** Accept data using `input()`.
4. **Processing:** Perform calculations or operations.
5. **Output Statements:** Display results using `print()`.

Example:

```python
# Input
a = int(input("Enter first number: "))
b = int(input("Enter second number: "))

# Processing
result = a + b

# Output
print("Sum =", result)
```
